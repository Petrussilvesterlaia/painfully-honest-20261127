One brutally honest but still polite out-of-office auto-reply, in a single sentence of 135 characters. It admits the sender is honestly relieved to be unreachable and that your email is waiting in a mountain of unread messages — and promises a fresh, patient reply on return, so a manager would let it stand.

## Run it

```sh
python3 main.py
```

The program writes the reply to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`), validates it first (one sentence, 1–200 characters, not only whitespace), and verifies it by reading the file back.
